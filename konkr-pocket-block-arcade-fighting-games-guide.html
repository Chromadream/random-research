Setup on the Block

  • Only 3–4 button games are listed here. The 6-button games (Street Fighter, Darkstalkers, Marvel, Mortal Kombat, Kaiser Knuckle) are on the separate Retroid Pocket Classic 6 list, whose Saturn-style face buttons suit them better.
  • Folders: Neo Geo games go in neogeo; the Capcom and Psikyo games go in fbneo. ES-DE's cps1/cps2/cps3 systems default to MAME – Current on Android, while neogeo and fbneo default to FinalBurn Neo.
  • Buttons: Neo Geo's A–D map straight to the four face buttons.
  • Scaling: Neo Geo and the Capcom boards are 224 lines, so 3× = 672 tall with the width stretched to 4:3. Daraku Tenshi is 240 lines, so 3× = 720 fills the screen.
  • Short bursts: an arcade ladder is roughly 10–15 minutes. Save-state before the boss if you only have a few stops.
  • Not here: 3D arcade fighters (Tekken, Soul Edge, Street Fighter EX) run on ZN boards that need MAME, so play their PS1 ports instead. Neo Geo Battle Coliseum and the other Atomiswave games need Flycast.
