Neo Geo

Switch to NeoMillie. Mazamars312's core was the only option for three years, but it hasn't changed since January 2023. NeoMillie is ported from the current MiSTer Neo Geo RTL and reads the same Darksoft-format ROM folders and BIOS, so you can install it alongside and move over without rebuilding anything.

ROM setup

Every arcade core loads a game as a small instance .json plus one .rom file built from your MAME-format zip. The Pocket can't read zips, so something has to assemble the chips first.

  1. JOTEGO cores: get the game's MRA from jtbin's mra folder and run mra my-game.mra with mra-tools-c in the folder holding the MAME zip. Copy the resulting .rom to Assets/<core>/common/, for example Assets/jtcps2/common/.
  2. Beta cores (anything marked Patreon): unzip jtbeta.zip from JOTEGO's Patreon into Assets/jtpatreon/common/ so beta.bin sits there. Once a core goes public, you no longer need it. Coin-Op Collection's Patreon cores use their own coinop.key instead; follow their install notes.
  3. Newer cores ship their own builders: tools/pocket/build_rom.py for Cave and Toaplan V2, tools/build_rom.py for Taito F3 and Psikyo, a browser page for DECO-32. System 32 and Namco System 11 have pupdate and Pocket Sync plugins that build the files straight onto the card.
  4. Match the romset version. Builders check CRCs against current MAME sets (SpaceFish names MAME 0.288). Clones need their parent zip unless your set is merged.
  5. Let an updater do the bookkeeping. pupdate and Pocket Sync install cores, list each core's required files and flag what's missing. Skipping _alternatives keeps the game lists short.

Saves, high scores and save states

  • No save states, almost everywhere. Of the 250 arcade cores, only Great 1000 Miles Rally and Nibbler declare sleep support, and none of the major ones offer Memories. Opening the Pocket menu pauses the newer cores (Cave, Toaplan V2, System 32, pre-GX), which covers a short break, but plan to finish a credit.
  • NVRAM and EEPROM do save. JOTEGO cores have an NVRAM slot; CPS2, Konami pre-GX and Namco System 11 keep each game's operator settings between sessions. Cave settings also stick. System 32 doesn't save high scores yet.
  • Change difficulty in the test menu. Cave, Toaplan V2 and others expose Test Mode under Core Settings.

Sources: jtbin wiki: Analogue Pocket cores, core READMEs above, inventory sleep_supported flags.

Screen and controls

The 1600×1440 panel is close to square. A 4:3 horizontal game fills 1600×1200, or 83% of it. A 3:4 vertical game held upright fills 1080×1440, or 68%. Turn the Pocket on its side in a core with a Tate setting and the same game gets 1200×1600, back to 83% and 11% taller. Vertical games are fine upright, and on a wide 16:9 handheld they'd lose far more.

  • Tate. Cave 68000 and Toaplan V2 offer Upright, Tate (left) and Tate (right) under Core Settings. Other cores show vertical games upright. In Tate the controls sit along the Pocket's long edges, which works best for shooters that only need shot and bomb.
  • Buttons. The Pocket has four face buttons in a diamond plus L and R. Select is coin, Start is start. Cave and Toaplan V2 put rapid fire on R. Remap per core under Controls in the Pocket menu.
  • Display modes. openFPGA cores get the Pocket's display modes from firmware 2.0, including the CRT Trinitron mode where the core allows it.
  • Dock. Up to four players on JOTEGO cores. Controllers 2 to 4 are ignored until you press an action button on each to claim it. System 32 accepts four (three and four untested) and FixEight three.
  • Analogizer. RndMnkIII's cartridge-slot adapter sends the board's own 15 kHz RGB to a CRT on JOTEGO, Cave, Toaplan V2, M72, Tecmo and Gauntlet cores, among others. Rotate the CRT for vertical games; the Tate setting only turns the Pocket's own screen.

Sources: Analogue Pocket specs (1600×1440, 360° rotation), Cave 68000 README (Tate, Analogizer), jtbin wiki (controllers), firmware 2.0 notes. Area figures are 4:3 and 3:4 output fitted to the panel.

Gotchas and what to watch

  • The late-2026 wave is young. Between September and November 2026, cores arrived for Atari System 2, Gaiapolis, Cave, Namco System 11, Toaplan V2, Neo Geo (NeoMillie), Taito F3, Psikyo, System 32 and Tekken 3, mostly from single developers testing on one Pocket. Back up Saves/ before updating, and keep the older core installed where one exists (Mazamars312 Neo Geo, plasticbugs Gaiapolis) until the new one proves itself.
  • Psikyo isn't ready. Strikers 1945 and Gunbird are listed, but only Tengai has booted on hardware.
  • Tekken 3 is a first experiment. McNast13's System 12 core is v0.0.1. Namco System 11 (Tekken 1 and 2, Soul Edge) is the more usable one, at 99% of the FPGA.
  • Duplicate cores clutter the menu. Twin Cobra, Flying Shark and Wardner exist as both JOTEGO betas and free Coin-Op cores; Turtles in Time, Gaiapolis, Smash TV, Sega System 1/2 and System C all come twice. Install one of each.
  • Headers and zips fail silently. A .rom built from the wrong set version either won't boot or boots with garbage. Rebuild with the core's own builder before blaming the core.
  • Patreon status changes weekly. JOTEGO releases new cores on Patreon first and makes them public later, so check before paying for one game. Currently beta on the Pocket: Gradius III, '88 Games, Space Harrier/Hang-On/Enduro Racer, Taito X, Rollergames, and JOTEGO's Twin Cobra/Flying Shark and Wardner (free from Coin-Op instead).
  • Watch for: Martial Champion and Monster Maulers on pre-GX, Fighter's History and Night Slashers on DECO-32, more System 32 games, ADPCM on System C, and the other Psikyo games booting.

For SD card basics, firmware and the GB/GBA side, see the Analogue Pocket Starter Guide.
