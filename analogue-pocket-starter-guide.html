Analogue Pocket Starter Guide

Update to firmware 2.7, let pupdate build the SD card, and make the Pocket your home for Game Boy, Game Boy Color, Game Gear and Neo Geo Pocket. Leave 4:3 consoles and long on-the-go JRPGs to handhelds that sync saves.

Day-one checklist

  1. Format a microSD card as exFAT (FAT32 also works, up to 1 TB) and boot the Pocket with it inserted once, so it creates its folder structure. Pocket Sync won't recognise a card the Pocket hasn't initialised.
  2. Update firmware. The latest is 2.7 (4 Sep 2026): drop the single .bin on the card root, with no other firmware files, and power on.
  3. Install pupdate (CLI, cross-platform) or Pocket Sync (GUI). Either one installs cores, firmware, BIOS files and arcade assets. Pick only the cores you want rather than everything.
  4. Turn on Tools > Developer > USB SD Access so you can manage the card over USB-C without pulling it. Since 2.1 you can also toggle it any time with Analogue + X (on) and Analogue + Y (off).
  5. Add your ROMs (No-Intro, unzipped) to each core's Assets/<platform>/common/ folder, plus the BIOS files the updater can't fetch (see the table below).
  6. Set Auto Dim and Auto Off under the power settings (added in 2.6).
  7. If you run GB games from carts, try Settings > Pocket > Systems > GB > Hardware > Force GBC Mode with an APGB palette, which makes DMG games look much nicer.
  8. Back up Saves/ and Memories/ before you try a flashcart or a new core version.

Pre-setting the card before the Pocket arrives: format it as exFAT and run pupdate -p /path/to/sdcard/. pupdate creates the folders, installs the cores you pick and drops the firmware .bin on the root, so it updates on first boot. Add ROMs and BIOS the same way. Only Pocket Sync has to wait, because it needs a card the Pocket has initialised.

Firmware, SD card and folders

Every openFPGA core is a zip you merge into the card root. The updaters do that for you, so you rarely touch the folders by hand except to add ROMs.

Folder What lives there
Assets/<platform>/common/ ROMs and BIOS for that platform, e.g. Assets/gba/common/
Cores/ Core bitstreams and JSON, one folder per Author.Core
Platforms/ Platform definitions and artwork; two cores for the same system share one platform and you pick via Change Core
Saves/ In-game saves (SRAM) per platform
Memories/ Save states and screenshots
System/ Settings, palettes, logs

Things worth knowing:

  • Removing a core means deleting its files from Assets, Cores and Platforms by hand. Updaters let you skip cores, so it's easier not to install clutter.
  • Core count limit. Firmware 2.7 raised the maximum platform/core count and made the cached core list load about twice as fast. Still, curate.
  • Two cores per system is normal. NES (spiritualized and agg23), GB/GBC (spiritualized and budude2) and Genesis (Eric Lewis and spiritualized) all have alternatives. Install both where one has a feature you need, such as budude2's RTC support.
  • Mac: when copying core zips manually, choose Merge, not Replace, or you'll wipe other cores' files.
  • Save sync: nothing on the Pocket syncs saves. With USB SD Access on, the card mounts like a drive, so a script that copies Saves/ to your Syncthing folder after a session is the practical bridge to your other handhelds.

Carts, adapters and flashcarts

For most GB/GBC play, openFPGA cores from the SD card make a flashcart unnecessary. Buy a flashcart only for the cases below.

When a flashcart (or real cart) is worth it

GB/GBC RTC games (Pokémon G/S/C) don't need a flashcart. Use budude2's GB/GBC core, which has RTC and full save states.

GB/GBC games with special cart hardware

On GB/GBC the extra hardware is inside the cartridge, and no GB/GBC flashcart we found replicates it. Play these on an AYANEO Pocket Vert instead. It has the same 1600×1440 3.5-inch screen as the Analogue Pocket, plus a gyroscope and a vibration motor that Android emulators can map to the cart's tilt sensor and rumble. For ordinary GB/GBC games on the Vert, either SameBoy or Gambatte is fine. The Game Boy Camera is the exception: play the real cart on the Analogue Pocket, which saves photos to the SD card.

Tilt (MBC7 accelerometer) Kirby Tilt 'n' Tumble, Command Master (JP) Pocket Vert with SkyEmu, which maps the gyroscope to the cart's tilt sensor. RetroArch won't do it: Gambatte has no tilt support, the SameBoy core's docs list sensors as unsupported, and mGBA is reported to misbehave in portrait. Which flashcarts

  • GB/GBC: EZ-Flash Junior (about US$59, built-in RTC, reported working on the Pocket) is the safe pick. The Everdrive GB X7 adds save states and has an Analogue Pocket compatibility toggle in its firmware.
  • GBA: The Everdrive GBA Pro (about US$129) is the pick. It's the only GBA flashcart with solar, tilt and gyro sensors, and it has a separate RTC per game plus save states. It has no rumble, and there's no public report yet of anyone testing it on a Pocket. The EZ-Flash Omega Definitive Edition (about US$75) is the cheaper choice if you only need RTC, and it does support rumble. The Everdrive GBA Mini (still listed by some resellers as the "X5 Mini") has no sensors. After saving on the Omega, wait about 10 seconds before powering off so it can copy the save to its SD card.
  • NGPC: the Pocket's adapters work with flashcarts. Time Extension ran a Retro HQ NeoPocket GameDrive through the NGP adapter.

The 2026 Everdrive warning

In June 2026 Krikzz reported that Pockets from a newer production batch corrupt the flashcart's file system when it writes a file, such as a save. The same firmware works on older units, so he blames a hardware change. Other reports point at component changes in newer Everdrive Minis. No fix had been reported, and Analogue doesn't support third-party carts. A Pink Classic Limited Edition went on preorder in November 2023, well before that batch, so this most likely doesn't apply to it. If you buy a newer Pocket:

  • Prefer EZ-Flash carts, or test an Everdrive with a throwaway save before trusting it.
  • Use the flashcart's own save system rather than Pocket Memories for anything you care about. Sleep/wake doesn't work reliably with Everdrives either.

Adapters

Analogue sells a Game Gear adapter and a three-pack for NGP/NGPC, Atari Lynx and TurboGrafx-16/PC Engine/SuperGrafx. Each has its own Original Display Modes, and Memories plus sleep/wake work for TG16/PCE/SuperGrafx and Lynx. Only Lynx actually needs an adapter: Game Gear, NGPC and PC Engine all have openFPGA cores.

Display modes, settings and features

The 1600×1440 panel is exactly 10× Game Boy resolution and an integer 6× for GBA. 4:3 home consoles end up letterboxed on its 10:9 shape. That's why the Pocket shines on handheld systems and is merely good on SNES or Genesis.

  • Original Display Modes. Analogue's cart cores and adapters get per-system LCD simulations. GBA offers Analogue GBA, Original GBA LCD and GBA SP 101, and Game Gear offers Analogue GG, Original GG and Original GG+. Since firmware 2.0, openFPGA cores can use them too. The CRT Trinitron mode unlocks automatically for suitable cores, but other modes only appear if the core author enabled them, so expect fewer options on community cores.
  • GB palettes. Firmware 2.0 added custom APGB palettes. Pair them with Force GBC Mode (checklist step 7) for the best results.
  • Memories (save states). Press Analogue + Up in game to save a state; screenshots and thumbnails sit alongside. Support depends on the core: yes for GB/GBC/GBA (budude2 too), PCE and Lynx via adapter; no for Neo Geo; SNES only in the drizzt nightly. A state from one game can't be loaded while another is running.
  • Sleep/wake. Pressing power mid-game suspends on cores that support it. Treat it like a save state, not a save, and don't rely on it with Everdrives.
  • Library and Boot to Cartridge. Inserted carts are catalogued in Library. Boot to Cartridge skips the Game Detail screen, which is handy for a dedicated Tetris DX cart.
  • Power. Firmware 2.6 added Auto Dim and Auto Off. Set them, because battery life is the Pocket's weak spot next to newer Android handhelds.

Sources: firmware 2.0 notes, Analogue Pocket page, 2.6 coverage, adapter firmware notes.

Dock

The Dock makes the Pocket a decent stand-in for a Super Nt / Mega Sg if you're happy playing ROMs, but not if you want to play SNES carts.

  • What it adds: HDMI out with the same Original Display Modes as handheld, and wired or Bluetooth controllers. Firmware 2.5 added the Nintendo Switch Online wireless pads via the Dock, and 2.6 added the 8BitDo 64. The Dock's own firmware updates through the Pocket's firmware file.
  • Aspect ratio: since 2.0, cores can output a different aspect ratio when docked. The letterboxing you get handheld on SNES and Genesis doesn't carry over to the TV.
  • Versus a Super Nt+: the Pocket plus Dock covers SNES, Genesis, PCE and Neo Geo from the SD card, with save states only where the core supports them. A Super Nt plays original SNES carts (and an FXPak). If the point is a cart collection, wait for the Super Nt+. If it's just playing SNES on the TV, the Dock covers it, and so does a docked PC handheld with shaders.

Sources: firmware 2.5 summary, firmware 2.6, firmware 2.0, Dock firmware via Pocket.

What to play on the Pocket vs other handhelds

Make the Pocket your home for the original handhelds whose resolution it was built around (GB, GBC, Game Gear, NGPC, oddball LCD systems) and for anything on cart. Leave 4:3 console systems and long on-the-go JRPGs to Android devices that sync saves.

Gotchas you might miss

  • Saves and Memories are different things. A Memory (save state) belongs to a specific core, so keep real in-game saves for anything long. Back up Saves/ before updating cores.
  • Updating cores can change behaviour. Some users found a GBA homebrew crashing on certain Pocket batches until they downgraded the spiritualized GBA core. If one game misbehaves, try another core version or the cart before blaming the ROM.
  • Headered or zipped ROMs silently fail. The Pocket won't read .zip, and SNES needs unheadered .sfc. Neo Geo wants Darksoft-format folders, not MAME zips.
  • No PAL on Genesis. Use NTSC/JP dumps.
  • Firmware updates need exactly one .bin on the card root. Remove old ones, or nothing happens.
  • Pocket Sync needs an initialised card. Boot the Pocket with the card once first.
  • Flashcarts: test Everdrive saves on a new unit before trusting them, and on the EZ-Flash Omega wait about 10 seconds after saving before you power off.
  • Homebrew .pocket files: GB Studio can export .pocket files that run on Analogue's own GB core from the SD card, so you get the official display modes and features without a cart.
  • Adapters are sold as a three-pack (NGP, Lynx, PCE), with Game Gear separate. Only buy them if you'll play original carts. Cores cover everything but Lynx.
  • Watch the core list. Check the openFPGA cores inventory occasionally for a GBA core with RTC (budude2's MiSTer port has been in progress) and for the SNES save-state build leaving nightly.
